2. Phân rã chức năng → test suite

Mỗi ô là một nhóm test case độc lập trong test plan.

CATALOG

Tìm kiếm; lọc hãng, danh mục, giá; phân trang/sắp xếp; chi tiết, ảnh, thông số và đánh giá sản phẩm.

Đăng ký, đăng nhập, refresh token, khóa tài khoản, cập nhật hồ sơ.

CART & ADDRESS

Thêm/sửa/xóa giỏ; kiểm tồn; CRUD địa chỉ; chuyển địa chỉ mặc định.

ORDER & COUPON

Tạo đơn từ giỏ/item; tổng giá; giảm giá; xóa giỏ; lịch sử đơn.

PAYMENT & REVIEW

VNPay URL/callback; COD; rating 1–5; một review mỗi user/sản phẩm.

ADMIN_RBAC

Dashboard; product/coupon CRUD; quản lý user; quản lý trạng thái đơn; kiểm thử phân quyền.

3. Luồng mua hàng và thanh toán

Đây là flow end-to-end trọng tâm cho test tích hợp và test hệ thống.

flowchart TD
  A([Đăng nhập]) --> B[Thêm sản phẩm vào giỏ]
  B --> C{Số lượng ≤ tồn kho?}
  C -- Không --> E[Thông báo lỗi]
  C -- Có --> D[Giỏ được cập nhật]
  D --> F[Chọn địa chỉ và phương thức]
  F --> G{Có coupon?}
  G -- Có --> H[Kiểm active / ngày / quota / min order]
  H -- Không hợp lệ --> I[Không tạo đơn]
  H -- Hợp lệ --> J[Tính total, discount, final price]
  G -- Không --> J
  J --> K[Tạo đơn PENDING + xóa giỏ]
  K --> L{VNPay?}
  L -- COD --> M[Hiển thị lịch sử đơn]
  L -- Có --> N[Tạo URL + payment PENDING]
  N --> O[VNPay callback]
  O --> P{Chữ ký hợp lệ & code 00?}
  P -- Có --> Q[Payment COMPLETED; đơn CONFIRMED]
  P -- Không --> R[Payment FAILED]

4. Vòng đời đơn hàng và tồn kho

Phủ test chuyển trạng thái hợp lệ/không hợp lệ và tác động tồn kho tại DELIVERED/CANCELLED.

stateDiagram-v2

  PENDING --> CONFIRMED
  PENDING --> SHIPPING
  PENDING --> CANCELLED
  CONFIRMED --> SHIPPING
  CONFIRMED --> CANCELLED
  SHIPPING --> DELIVERED: trừ kho, tăng sold
  SHIPPING --> CANCELLED
  DELIVERED --> RETURNED
  DELIVERED --> CANCELLED: hoàn kho, giảm sold

8. Coverage phi chức năng, dữ liệu và tích hợp

Đây là phần còn thiếu nếu chỉ dừng ở use case; cần đưa vào test plan để đánh giá toàn diện.

Security

401/403; JWT giả mạo/hết hạn; refresh replay; IDOR; XSS ở name/comment/note; SQL injection; CORS; không lộ password/token/error stack.

Database & transaction

Foreign key/cascade; unique email/slug/coupon; rollback khi tạo đơn/payment lỗi; concurrent checkout cho tồn kho cuối; coupon dùng đồng thời.

Performance

Tải danh sách và tìm kiếm với dữ liệu lớn; tạo đơn đồng thời; thời gian API; phân trang; tải đồng thời theo mục tiêu lớp đặt ra.

Reliability

Mất mạng/timeout; backend 5xx; VNPay callback trễ/lặp; refresh lỗi; retry không nhân đôi order/payment/coupon count.

Usability & accessibility

Mobile/desktop; Chrome/Edge/Firefox; tab keyboard; focus; label form; lỗi dễ hiểu; màn hình empty/loading/error; màu đủ tương phản.

Data integrity

Total/discount/finalPrice nhất quán; stock/sold không âm; default address đúng một; order/payment/review liên kết đúng chủ sở hữu.

9.2 Transaction, đồng thời và test data

Atomicity

Buộc lỗi ở mọi bước tạo đơn: không được còn order, order_item, coupon used_count hoặc cart bị xóa dở dang. Kiểm chứng rollback bằng query trước/sau.

Concurrency

Hai user mua lượng tồn kho cuối; hai request dùng coupon ở lượt cuối; hai callback VNPay cho cùng order. Kết quả không oversell, không double count, không duplicate payment.

Isolation

Không hiển thị dữ liệu nửa chừng; total, stock, used_count và trạng thái order nhất quán giữa các request đồng thời.

Test fixtures

Chuẩn bị user USER-A/USER-B/ADMIN; product stock 0/1/n; coupon active/inactive/expired/future/maxed; cart empty/full; order ở mọi status; payment pending/completed/failed.

Migration & recovery

Chạy schema.sql từ database trống; nạp data.sql; chạy lại không phá dữ liệu; backup/restore test DB; không thử trực tiếp trên production.

DB security

Tài khoản ứng dụng quyền tối thiểu; mật khẩu DB không commit; không trả SQL exception ra UI; phân tách test/staging/production; dữ liệu cá nhân được che trong report.
