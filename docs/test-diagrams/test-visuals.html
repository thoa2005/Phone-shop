P1 · Ownership

USER-A không được đọc đơn, sửa/xóa địa chỉ hoặc dùng addressId của USER-B.

P1 · Tồn kho

Quantity vượt stock bị chặn tại giỏ hoặc checkout; hai người mua stock cuối không oversell.

P1 · Trạng thái

Chặn CANCELLED → SHIPPING, RETURNED → DELIVERED và mọi bước ngoài state machine.

Thứ tự chạy khuyến nghị: Smoke → P1 security/data → Critical E2E → Regression API/UI → Non-functional.

12 · Ma trận kiểm thử database

Test constraint, cascade, transaction, concurrency, recovery và bảo mật dữ liệu.

Đối tượngRàng buộcTest bắt buộc
usersemail UNIQUE; required; role; activeEmail trùng/null; password hash; inactive không login; không lộ password.
productsslug UNIQUE; price/stock; FK SET NULLSlug trùng; âm/biên; xóa category/brand; cascade image/spec; soft delete.
cart / items1 cart/user; FK CASCADEDuplicate cart; qty ≤0/vượt kho; xóa user/cart; không orphan item.
addressesuser FK CASCADE; defaultOwnership; đúng một default/user; addressId khi checkout.
couponscode UNIQUE; type; counter/dateQuota đồng thời; min/value/date; SET NULL khi coupon đã dùng bị xóa.
orders / itemsFK; item CASCADE; address/coupon SET NULLSum item = total; discount/final; snapshot price; không orphan.
paymentsorder_id UNIQUE; requiredCallback lặp; amount = finalPrice; transactionId; cascade khi xóa order.
reviewsrating CHECK 1..5; FK0/6; cascade user/product; order SET NULL; tính lại avg_rating.

ATOMICITY

Ép lỗi từng bước checkout; rollback order/item/coupon/cart hoàn toàn.

CONCURRENCY

Hai user mua stock cuối; coupon lượt cuối; hai callback cùng order.

ISOLATION

Không đọc dữ liệu nửa chừng; totals/stock/status nhất quán.

FIXTURES

USER-A/B/ADMIN; stock 0/1/n; coupon mọi trạng thái; order/payment mọi state.

MIGRATION & RECOVERY

DB trống → schema/data; rerun; backup/restore; không test production.

DB SECURITY

Least privilege; không commit secret; che PII; không lộ SQL exception.
